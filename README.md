# Мой автобус

Android-приложение и домашние виджеты с прогнозом прибытия общественного
транспорта. Пользователь добавляет остановку, направление и автобусы, при
необходимости объединяет несколько маршрутов и видит ближайшее время прямо на
главном экране телефона.

Актуальная версия: **4.1** (`versionCode 20`). Минимальная версия Android — 8.0.

При первой установке уже добавлены три направления к метро «Саларьево»:
«Саларьевская улица, 13», «Саларьево Парк» и «Улица Большое Понизовье».
В каждом направлении объединены автобусы 272 и 420. Ненужные направления можно
удалить в приложении; после этого они не добавятся снова.

![Для чего создано «Мой автобус»](docs/moi-avtobus-meme.png)

## Возможности

- ровно два прозрачных виджета: тёмный и светлый;
- каждый виджет изменяется от большого размера до 1×1;
- два ближайших прибытия видны во всех размерах: `2 | 5 мин`, а в 1×1 — `2 | 5`;
- живое время окрашивается зелёным, расписательное — серым;
- живые прогнозы имеют приоритет: два зелёных времени не заменяются серым расписанием;
- произвольные пользовательские разделы: «До метро», «До дома» и другие;
- объединение автобусов одного направления с выбором двух самых ранних машин;
- обновление обычного виджета нажатием на него;
- автоматическое фоновое обновление и сохранение последнего прогноза при
  кратковременном сетевом сбое;
- светлая и тёмная версии виджетов при неизменно тёмном интерфейсе приложения.

## Установка готового APK

[Скачать Moi-Avtobus-v4.1.apk](releases/Moi-Avtobus-v4.1.apk)

SHA-256: `1D7FC9FB8C4CDE4F922596BB86ADCD32975D3C37666B515EB32AFEF2A846C547`

1. Скачайте или передайте на телефон файл `Moi-Avtobus-v4.1.apk`.
2. Откройте файл и разрешите установку из этого источника, если Android спросит.
3. Запустите «Мой автобус», удалите ненужные предустановленные направления или
   добавьте свои маршруты.
4. Откройте список виджетов домашнего экрана и выерите тёмный или
   светлый вариант «Мой автобус».

Для приложения не требуется ключ Yandex MapKit.

## Сборка из исходников

Требуются JDK 17, Android SDK 36 и подключение к интернету для первой загрузки
зависимостей.

В Android Studio откройте корень репозитория и дождитесь Gradle Sync. Или
выполните из терминала:

```powershell
./gradlew.bat :app:assembleDebug
```

На Linux/macOS:

```bash
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Данные и сеть

Приложение обращается к сервису городского транспорта Москвы
`api.moscowapp.mos.ru` и обрабатывает прогнозы остановок. Учётная запись,
геолокация телефона и ключ API не используются. Доступность и точность
прогнозов зависят от внешнего источника данных и сети устройства.

Проект не является официальным приложением Правительства Москвы, Яндекса или
перевозчика.

## Структура

- `app/src/main/java/ru/salarevo/buswidget` — логика приложения, сети и виджетов;
- `app/src/main/res/layout` — экраны и макеты виджетов;
- `app/src/main/res/xml` — описания двух адаптивных Android-виджетов;
- `docs/ARCHITECTURE.md` — краткое устройство проекта;
- `CHANGELOG.md` — изменения финальной версии.
- `INSTALLATION.md` — подробная инструкция по установке и виджетам.

Сторонняя зависимость: AndroidX WorkManager 2.10.1.
