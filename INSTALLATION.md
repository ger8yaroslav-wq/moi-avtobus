# Установка «Мой автобус» 4.1

## Что требуется

- Android 8.0 или новее;
- подключение к интернету;
- файл `Moi-Avtobus-v4.1.apk`.

Ключ Yandex MapKit, учётная запись и доступ к геолокации телефона не требуются.

## Установка APK

1. Скопируйте `Moi-Avtobus-v4.1.apk` на телефон.
2. Откройте файл через проводник, Telegram, браузер или другое приложение, куда он был скачан.
3. Если Android покажет запрос, разрешите этому источнику «Установку неизвестных приложений».
4. Нажмите «Установить». При обновлении старой версии кнопка может называться «Обновить».
5. Запустите «Мой автобус». При чистой установке уже добавлены три направления
   к метро «Саларьево»: от «Саларьевской улицы, 13», «Саларьево Парка» и
   «Улицы Большое Понизовье». В каждом объединены 272 и 420. Удалите ненужные
   направления или добавьте свои.

При обновлении поверх старой версии сохранённый пользователем список не
заменяется предустановленным. Чтобы увидеть состояние чистой установки, нужно
сначала удалить старую версию; при этом её настройки тоже будут удалены.

## Добавление виджета

1. Зажмите свободное место на главном экране.
2. Откройте пункт «Виджеты».
3. Найдите «Мой автобус» и выберите тёмный или светлый вариант.
4. Выберите раздел, который будет показан в компактном размере.
5. Изменяйте размер за края виджета. В 1×1 останутся только два времени, например `11|17`.

## Цвета времени

- зелёный — живой прогноз по телеметрии;
- серый — время из расписания.

Если доступны два живых прогноза, оба будут зелёными. Серое расписание используется только для заполнения отсутствующего второго живого времени.

## Если Android сообщает о конфликте подписи

Это означает, что на телефоне установлена сборка с другой цифровой подписью. Можно удалить старую версию и установить APK заново. При удалении будут также удалены сохранённые маршруты.
